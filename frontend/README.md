# Inkstave frontend

The Inkstave web client: a **Vite + React + TypeScript** app with Tailwind, shadcn/ui,
CodeMirror 6 and PDF.js. How it is built: [`docs/system/frontend.md`](../docs/system/frontend.md).

Managed with [`pnpm`](https://pnpm.io/) via the root `pnpm-workspace.yaml`. Commands live in the
root `Makefile`: `make web-dev`, `make web-test`, `make web-build`, `make web-types`.
