# Spec 114 — Symbol palette, table builder and visual equation editor (prompt)

Three insert tools for the parts of LaTeX that are tedious to type: a searchable palette of math symbols, a
table builder that turns a grid (or a paste from a spreadsheet) into `tabular` code, and a visual equation
editor that opens on the math under the cursor and writes LaTeX back. Read `spec.md`, then implement it with
its tests.

Depends on 18 and 107. Read `docs/system/frontend.md` first.
