# 107 — Editor focus layout

Prompt: the user found the editor screen confusing, with too much on it, and the agent poor. Directions were
validated on an interactive demo. The user chose: the text and the PDF always fixed, the file list on
demand as a small drawer on the left over the text, with a shade behind it, the agent as a window in the
lower right corner, and an "ask the agent" offer on selected text. A phone layout was left to the
implementer.

Requirements: [spec.md](spec.md).
