# Spec 118 — Comments on the text (prompt)

Let members comment on a passage: select text, write a comment, and the comment stays attached to that passage
while the text around it changes. Others reply in a thread, resolve and reopen it, and `@mention` collaborators,
who get a notification. Read `spec.md`, then implement it with its tests.

Depends on 28, 39, 117 (project event stream). Read `docs/system/collab.md`, `docs/system/notifications.md` and
`docs/system/discussion.md` first.
