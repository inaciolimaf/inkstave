# Spec 112 — LaTeX autocomplete (prompt)

Make the editor suggest as you type: commands and environments with snippets, `\cite` keys from the project's
`.bib` files, `\ref` targets from every `\label`, file paths for `\input` and `\includegraphics`, and package
names for `\usepackage`. Read `spec.md`, then implement it with its tests.

Depends on 18 and 111 (the project index). Read `docs/system/frontend.md` first.
