# Spec 116 — Share by link (prompt)

Let an owner share a project with a link instead of an e-mail invite: one link to view and one to edit, each
can be turned on, rotated or turned off. Anyone with an account who opens a link joins with that role; turning a
link off removes the people who joined only through it. Read `spec.md`, then implement it with its tests.

Depends on 33, 34, 109. Read `docs/system/sharing.md` first.
